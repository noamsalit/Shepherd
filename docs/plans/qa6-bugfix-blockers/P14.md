## Fix

- **BC-06 body:** `stepBody(kind, data)`. For `tool_call`, the body names `detail.input`'s keys, sorted:
  `arguments: brief, cwd`. It shows `(no arguments)` for `{}` and `—` when `input` is not an object.
  Values are never shown. For any other tool-named kind (`tool_result`), the body is `data.text`, or
  `(no result text)` when that is empty or missing. `shepherdStep` now takes a string body, so no
  object reaches `textContent`.
- **BC-25 composer:** `submit()` returns when `text.trim() === ""`, and posts the text untrimmed.
  `onComposerKey` returns early when `event.isComposing`.
- **BC-26:** `shown(id)` checks `state.approvals` and every `[data-approval-id]` card, comparing
  `dataset` rather than building a selector. The `approval.created` branch skips an id that is already
  shown. `loadShepherd` appends only the ids that are not yet shown.

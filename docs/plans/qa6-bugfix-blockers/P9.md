## Fix

- `engines/claude_code/ingest_socket.py`: `CLAIM_PROBE_TIMEOUT_S = 0.25`; `class SocketInUse(RuntimeError)`
  (deliberately not an `OSError`, so `controld.main`'s held-port branch cannot swallow it);
  `_is_live(path)` (AF_UNIX connect within 0.25 s, then close unread); `claim_socket(plan) -> SocketPlan`
  (raises `SocketInUse(f"{plan.path} is held by a running process")` when the path exists and a connect
  succeeds; a refused/absent path returns `plan`). `bind_listener` calls `claim_socket(plan)` before
  `unlink_socket`, so both listeners are covered. Module docstring's unlink rule amended.
- `daemons/control_ingest.py`: hello `sendall` inside `try … except OSError: continue`; `SocketInUse`,
  `claim_socket` join the `ingest_socket` import and `__all__`.
- `daemons/sessiond.py`: `ingest = claim_socket(host.control_socket(INGEST_SOCKET_NAME))` inside the
  existing refusal `try`; `except (SocketPathTooLong, SocketInUse)` prints `sessiond refuses to start: …`
  (stderr, as the existing refusal does), exit 2. 111 lines (cap 150).
- `daemons/controld.py`, net zero: line 30 import, line 40 `MigrationRefused`, line 71
  `plan = claim_socket(...)` (before `open_store`), line 122 `except (SocketPathTooLong, SocketInUse, MigrationRefused)`.
  **140 lines**, `RESERVED_FOR_M2` untouched.
- `engines/claude_code/hooks_config._load`: `except PermissionError as error: return None, f"settings file cannot be read ({error.strerror}), so it is left untouched"`.

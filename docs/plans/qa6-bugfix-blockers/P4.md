## Fix

- **BC-04** `_idle_crossed(entry, liveness, prior, observed_at, now) -> bool` (plan's signature): equal
  stamps, `status == idle`, `liveness_verdict` holds, `prior.state is RUNNING`, age ≥ 60 s. It is a
  fourth conjunct of RD8's early-return condition, so when it holds the pass falls through to the
  existing live-process path, which already yields `NEEDS_YOU` / `IDLE_REASON` with
  `observed_at` = the unchanged stamp and one `session.state` event. A strictly newer prior still
  returns early (the `>=` is untouched); the busy-entry tie test is untouched.
- **BC-17** `scan_registry(config_dir, *, consult_agents_fallback=True)` returns `([], ())` for a
  missing `sessions/` when false. `discovery_pass(..., *, consult_agents_fallback=True,
  reported_problems=None)`; `run_discovery_loop` passes `True` on its first pass, `False` after.
- **BC-27** `_unreported(anomalies, reported)`: with a set, only details not already in it are bumped,
  then the set is replaced by this pass's details (healed-then-broken counts again, E9). The loop owns
  the set. `None` (a lone `discovery_pass`) keeps the old count-every-one behaviour.
- **BC-34** `discovery_pass`'s `replace(event, …)` also sets
  `payload={**event.payload, PROJECT_ID_KEY: session.workspace_id}`. `PROJECT_ID_KEY = "project_id"`
  is restated in `signals/` (it cannot import `web/`), with a comment naming `web/sse.envelope`.

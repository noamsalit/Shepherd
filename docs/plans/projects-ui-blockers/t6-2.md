# T6.2 — the three renames, at their source

## What changed

`src/shepherd/core/stops.py`, three `label` strings in `PALETTE`:

| bucket | was | is |
| --- | --- | --- |
| `Bucket.UNFINISHED` | `unfinished` | **`stranded`** |
| `Bucket.PAUSED` | `paused` | **`limit exceeded`** |
| `Bucket.UNCLASSIFIED` | `not classified` | **`unknown`** |

Bucket **values** are untouched. `signals/stop_rules.py`, the store's columns
and the 90-day stop log all key on `Bucket.<NAME>.value`; a rename that moved a
value would silently re-partition ninety days of recorded history, while a
rename that moves a label changes a word on a screen. `grep` confirms the three
strings existed in exactly two places before this task — `stops.py` and
`fleet.js`'s table — and in one after it, because `fleet.js` is gone.

## Why there is no UI-side label table

`test_palette_matches_core_stops` reads the page's tables back out of `flock.js`
and compares them to `PALETTE`. A second table would either be checked against
the first — and be redundant — or not be, and be the drift the test exists to
catch. That is the whole argument, and it is why the renames land here.

`BUCKET_ACTS` joined the compared set in the same task: U10's legend carries an
`acts:` line and `who_acts` is a `PALETTE` field, so it is compared for exactly
the reason the label and glyph tables are.

`test_palette.py`'s `fleet_js()` helper became `flock_js()` **in this same
breath** (F3). It read the module the page no longer renders from; leaving it
would have left every assertion in that file green against bytes nothing serves
— which is the failure the file exists to prevent one layer up.

## The 300-line cap, and what it cost

`tests/test_core_stops.py::test_module_imports_nothing_above_l1_and_has_no_logic`
asserts `len(source.splitlines()) <= 300`, and `stops.py` was at **exactly 300**.
So the `PALETTE` comment documenting this decision is two lines, not the eight
it wanted, and the reasoning lives here and in `test_palette.py`'s docstring
instead. Recorded because the next person to document a decision in that table
will hit the same wall and should move the cap deliberately rather than
discover it.

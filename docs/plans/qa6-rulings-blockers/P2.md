## REM-FIX 1 (code-reviewer + failure-hunter, cross-confirmed; router decision)

**Deviation from plan P2.** The plan says uninstall writes the backup with `"xb"`. That was a plan
defect: uninstall's pre-image always holds our entries (the file had to hold them for uninstall to
get this far), so a backup created by uninstall is never a pre-install image. Example: install into
an absent file (no backup, nothing to back up), then uninstall. The old code created a backup
holding Shepherd entries. The router fixed this inside P2 under the owner's autonomy grant.

Changes, all in `hooks_config.py`:
1. **Uninstall never writes a backup.** It reports the backup an install kept if a regular file is
   there, else `settings_path` (the existing "no backup" value).
2. **A failed backup write leaves nothing.** `_keep_first_backup` opens with `"xb"`. On any
   `OSError` during the write or close it unlinks the file it created (`missing_ok`) and re-raises.
   The install then writes nothing (as before, the raise propagates before the settings write), and
   the next install writes a correct backup. This closes the "truncated backup kept forever" sibling
   listed above.
3. **Only a regular file is a backup.** When the path already exists (`FileExistsError`), a
   directory or any symlink (dangling or not) is not reported: `backup_path` is `settings_path`
   and a warning names the path. Uninstall applies the same rule.
4. **A kept backup that is not this run's is reported.** Bytes that differ from this run's
   pre-image give the warning `backup at <path> is the first pre-install image, not this run's`.
   Bytes containing `_shepherd_managed` give `backup at <path> holds Shepherd entries` (a backup
   left by an older build that overwrote it). The warnings go only in `InstallResult.warnings`,
   which `cli/` already prints (`cli/` not edited, frozen until P10). A first install with no
   earlier backup still has `warnings == ()`, so the e2e `warnings == ()` asserts are unaffected.
   A re-install now has one warning (the first-image one). No test asserted otherwise.

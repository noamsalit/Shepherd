### Findings and fixes

1. **(HIGH) A claim the kernel refuses was reported as a held port.** `claim_socket`'s non-EWOULDBLOCK
   `OSError`s (mkdir/chmod of the socket dir, `os.open` of `<socket>.lock`, `flock` `ENOLCK`/`EACCES`)
   reached `controld.main`'s `except OSError` arm ("port N is not available"), and escaped
   `sessiond.main` as a traceback. Fix: `ingest_socket.ClaimFailed(RuntimeError)`, raised by
   `claim_socket`/`_take_lock` with `cannot claim <lock-or-dir path>: <strerror>`; the descriptor is
   closed and nothing is recorded in `_HELD`. Only `BlockingIOError` stays `SocketInUse`.
   `control_ingest` re-exports it (`__all__`) and both `main`s list it in their refusal arm.
   `controld.py` stays **140** lines (the arm is one line, re-wrapped in place with a `# D72: not a port`
   note); `sessiond.py` 114 → 120 (import re-wrapped). `bind_listener`'s own `mkdir`/`chmod`
   before `claim_socket` dropped: `claim_socket` makes the same dir at the same mode first, and the
   duplicate would have let a dir failure bypass `ClaimFailed`.
2. **(HIGH) `test_a_newer_schema_closes_the_port_it_bound` passed vacuously.** The spy kept only the
   port number, so a start that never closed its server was rescued by GC closing the unreferenced
   socket. The spy (`server_spy`) now keeps the server, the test holds `as refused` (its traceback keeps
   `start`'s frame and `server` local alive), and `assert_the_port_was_given_back` checks both
   `server.socket.fileno() == -1` and the rebind.
3. **(MEDIUM) no test for a compose that raises.** New
   `test_a_compose_that_raises_closes_the_store_and_the_port`: `compose_tool_surface` spy raises, an
   `open_store` spy keeps the store; asserts `not store.writer_is_alive()` and the port given back
   (server referenced, `as refused` held).
4. **(MEDIUM) BlockingIOError-only mapping unpinned.** New parametrized
   `test_only_a_would_block_lock_is_a_socket_in_use[EWOULDBLOCK|ENOLCK|EACCES]`.
5. **(MEDIUM/LOW) release not exception-safe.** `release_claim` pops, unlocks and closes inside
   `_HELD_GUARD`, `try: flock(LOCK_UN) finally: os.close(fd)`. Both listeners' `finally`
   (`control_ingest.serve_control_ingest`, `ingest_socket.serve_ingest`) call `release_claim` in a nested
   `try/finally` after `unlink_owned_socket`.

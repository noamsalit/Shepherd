## Deviations

1. **The guard run needs two aids that a worktree lacks, and both were temporary.**
   - `paths.PYTEST` is `REPO/.venv/bin/pytest`, and `REPO` is the worktree, which has no `.venv`.
     All 63 `test_mutation_reproves_copied_module[*]` cases raised `FileNotFoundError` for
     `…/qa6r-P1/.venv/bin/pytest` before any edit took effect. This is environmental.
   - `test_guard_catalog_reconciles_with_the_plan` reads
     `REPO/.cc10x/qa/wf-20260923T182839Z-9adb11fc/test-plan.md`, which is untracked and exists
     only in the main checkout.

   The guards therefore ran through a wrapper (scratchpad `guards.sh`). It symlinks `$W/.venv` to
   the main `.venv`, copies `test-plan.md` into `$W/.cc10x/qa/<wf>/`, clears `tests/qa6`
   `__pycache__`, runs the guards with `PYTHONPATH=$W/src`, and then removes both aids. `git
   status` after the run shows only the intended files. Any later phase that runs the guards in a
   worktree hits the same two gaps.
2. **The decision counts in `README.md:118` and `HANDOFF.md:17` were moved too.** Each file uses
   its own counting convention, and both now say 80 (D1–D79 plus D38.1). The plan names only the
   spec's `:34`, but both files are already P1 files. Leaving them at 68 would contradict the spec
   this phase edits. No test pins either line.
3. **D12's decision clauses were renamed** (three `…mechanical_1_0` names, listed above). The plan
   names only the stream rename. A clause named `mechanical_1_0` that asserts `(0.0, "mechanical")`
   or `heuristic` would misreport itself. All three were FAIL in the comparison set.
4. **D74 cites O51 as the QA test-plan's oracle** ("writes only to owned sessions"). The ruling says
   "spec O51", but `orchestrator-platform.md` has no O51.
5. **ADR-M4-7's amendment sits directly after the heading** (plan: "after line 814", the heading
   line), not after the ADR's Consequences.
